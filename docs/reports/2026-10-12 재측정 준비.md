## 4. 필요한 한도 추정

### 4.1 Claude 주간 사용률

| 근거 | 값 |
|---|---|
| 2단계 시험 (Claude만, 작업 5개) | 기능 전체 20% → 25%, 약 5%p. 측정 구간 API 환산 약 $7.75 |
| 3단계 시험 (작업 5개) | API 환산 약 $14.33 (2단계의 1.85배). 주간 초기화가 끼어 퍼센트는 재지 못했다. 비율로 환산하면 약 9%p |
| 흐름 확인 (비용 개선 뒤, 작업 3개, 작은 명세) | 69% → 72%, 약 3%p |

- 추정: 재측정(같은 명세, 작업 5개 안팎)은 약 5~9%p다. 넉넉히 잡아 10%p다.
- 권장: 시작할 때 남은 양이 15%p 이상이어야 한다(주간 사용률 85% 이하). 측정 중에 주간 초기화가 끼면 퍼센트 비교가 깨진다. 주된 비교는 토큰과 API 환산이다.
- 이 세션을 포함해 다른 Claude 세션을 측정 중에 쓰면 사용률에 섞인다.
